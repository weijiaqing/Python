# 한글 365 — 韓文每日練習

從零基礎開始、為期一年的韓文自學 App。可以「加到主畫面」當成手機 App 使用，離線也能跑，進度存在手機本機。

介面語言為繁體中文，內容以現代首爾標準韓語為準。

---

## 課程設計

52 週 × 7 天 = **364 課**（每週 6 天新課 + 1 天複習），累積 **1,968 個不重複單字**與 **1,124 個例句**。

| 階段 | 週次 | 內容 |
|---|---|---|
| 1 · 文字基礎 | 1–4 | 40 個字母、音節結構、七條發音變化規則、外來語、第一組問候 |
| 2 · 生存韓語 | 5–13 | 이에요/예요、指示詞、있어요/없어요、兩套數字、해요體、助詞、時間、過去式、餐廳 |
| 3 · 基礎會話 | 14–26 | 否定、未來與意志、請求許可、連接語尾、敬語系統、七種不規則、購物、交通、天氣、情緒 |
| 4 · 自然口語 | 27–39 | 반말、-는데、語尾語氣（-네요/-잖아요/-거든요）、推測、間接引用、回想、被動使動、職場、慣用語、網路用語 |
| 5 · 實戰溝通 | 40–52 | 銀行行政、租屋、醫療、稱謂與年齡文化、節慶、酒席文化、新聞漢字詞、表達意見、旅行、人際、書寫 |

走完一年約達 **TOPIK 3 級**（能進行日常社交、處理熟悉話題）。

### 內容取向

- **現代用法優先**：教 ㅐ/ㅔ 已經合併、ㅚ/ㅙ/ㅞ 同音、`너무` 現在正面也能用、`아아`／`맛집`／`ㅋㅋ` 這類實際會遇到的說法。
- **文化與文法並重**：30 則以上的文化筆記，涵蓋 눈치、회식禮儀、안녕히 가세요 vs 계세요、오빠 的使用界線、전세사기 風險等。
- **語體優先於文法**：反覆強調對誰該用哪一種語尾——這比文法錯誤更容易造成失禮。

## 功能

- **今日課程** — 文法說明（繁中）、單字、例句，全部可點擊聽發音
- **自動出題** — 每課 12 題，五種題型：中→韓、韓→中、聽力、句子重組、克漏字。題目由當週內容自動生成，干擾選項取自同週單字
- **間隔重複記憶卡** — 完成課程的單字自動進入 SRS 排程（again / hard / good / easy 四級評分）
- **字母模組** — 子音母音收尾音對照表、八條發音變化規則、羅馬拼音即時轉換工具
- **課程表** — 52 週全部可瀏覽、可跳到任何一天
- **一年原稿紙** — 以韓國原稿紙為原型的進度格，每完成一天就填上那天的第一個字
- **設定** — 拼音開關、發音語速、深淺色、進度匯出／匯入、重置

### 羅馬拼音是算出來的，不是寫死的

`src/app.js` 內含一個 Revised Romanization 轉寫器，實作了實際發音規則：

連音、鼻音化、流音化、激音化、ㅎ 脫落、口蓋音化、ㄹ 鼻音化、收尾音中和。

```
한국어  → hangugeo      감사합니다 → gamsahamnida
연락    → yeollak       좋아요     → joayo
같이    → gachi         독립       → dongnip
```

例外：ㄴ 添加（십육 → simnyuk）需要判斷複合詞的語素邊界，純字元演算法做不到，因此以一份小型例外表處理常見字。

## 安裝到手機

### iPhone / iPad
1. 用 **Safari** 開啟 `dist/index.html` 的網址
2. 點下方分享鈕 → **加入主畫面**

### Android
1. 用 **Chrome** 開啟同一網址
2. 選單 → **安裝應用程式** / **加到主畫面**

裝好後會以全螢幕開啟、有自己的圖示，斷網也能用（service worker 快取整個 App）。

> 進度存在瀏覽器的 localStorage，清除瀏覽資料會一併清掉。換手機前請用「設定 → 匯出進度」備份。

## 開發

```
korean-app/
├── build.mjs            # 把 src/ 打包成單一 HTML
├── src/
│   ├── shell.html       # 版面骨架
│   ├── styles.css       # 設計 token 與樣式
│   ├── app.js           # 引擎：羅馬拼音、SRS、出題、各頁面
│   └── content/         # 課程資料（10 個檔案，依週次分割）
├── public/              # manifest.webmanifest、sw.js
└── dist/                # 產出
    ├── index.html       # 完整文件（PWA 用）
    └── artifact.html    # 片段（Claude Artifact 用）
```

```bash
node build.mjs      # 產出 dist/
```

沒有相依套件，不需要 `npm install`。

### 課程資料格式

```js
W(週次, "中文標題", "한국어 제목", [
  {
    t: "課程標題",           // 中文
    k: "수업 제목",          // 韓文
    hero: "안녕하세요",       // 卡片主字（可省略，預設取第一個單字）
    heroZh: "你好",
    g: "<h3>…</h3>",         // 文法說明 HTML
    c: "<h3>…</h3>",         // 文化筆記（可省略）
    letters: [[字母, 拼音, 唸法, 註記]],   // 僅字母課
    v: [["단어", "單字", "備註"]],
    s: [["문장이에요.", "這是句子。"]]
  },
  … 共 7 天，第 7 天為 { t:"…", review:true }（自動彙整當週內容）
])
```

羅馬拼音不用寫，由程式產生。

## 已知限制

- **發音**由瀏覽器的 Web Speech API（`ko-KR`）合成，品質視裝置而定；iOS 與 Android 內建的韓語聲音都堪用，桌面瀏覽器可能需要另外安裝語音包。
- 字型透過 Google Fonts 載入；離線時會退回系統韓文字型，排版略有差異但完全可讀。
- 這是**自學教材**，不能取代跟真人對話。第 26、39、52 週都有提醒：實際開口練習才是流利的關鍵。
